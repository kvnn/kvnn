## Featured project: LitScenes

[LitScenes](https://github.com/litscenes/litscenes) is an open-source, native macOS app for turning stories and your own media into AI video.

Built in Swift, it brings story development, scene planning and media generation into one creative workspace. A knowledge graph drawn from literature connects situations, symbols and themes to the scenes you create. The app runs locally and connects to model providers using your own API keys.
